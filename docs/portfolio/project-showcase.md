# Project Showcase Presentation Model

## 1. Overview
The Project Showcase presents both public clients and internal stakeholders with a multi-dimensional perspective of software delivered by KDI AI Office:

```text
Project Showcase
├── Hero Header & Categorization
├── Live Action Links (Demo, Open Source Repository, Graph Pivot)
├── Problem Statement & Engineered Solution
├── Interactive Architecture Diagram (Layered System Tiers)
├── In-Depth Engineering Case Study (Context, Constraints, Lessons)
├── Collaborative Workforce (Human Leadership + AI Agent Roles)
├── High-Resolution Media Gallery (Screenshots, Videos, Diagrams)
└── Verified Quantitative Results & Metric Badges
```

## 2. Component Structure
- `PublicProjectShowcaseModal`: Unified modal dialog rendered either over the 3D PlayCanvas scene or on top of the 2D grid.
- `ArchitectureViewer`: Tiered component visualizer with data flow steps.
- `CaseStudySection`: Segmented tabs exploring technical constraints and implementation realities.
- `AiContributionBadge`: Transparent distinction of human governance vs automated AI implementation.
- `MediaGallery`: Responsive media cards with lightbox and broken-image fallbacks.
