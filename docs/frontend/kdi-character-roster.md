# KDI AI OFFICE — ORIGINAL CHARACTER ROSTER & IDENTITY DIRECTORY

## 1. Architectural Philosophy: Presentation Identity vs. Operational Identity

In KDI AI Office, character presentation identities are strictly decoupled from operational backend agents:

$$\text{Visual Character Identity (Presentation)} \neq \text{Backend Agent Runtime (Operational)}$$

- **Presentation Identity**: Character names, visual hairstyles, clothing, personality traits, and dialogue style provide an engaging, cozy, and original virtual office narrative.
- **Operational Identity**: Stable machine identifiers (`AGT-SALES-001`, `AGT-ENG-001`, `AGT-ARCH-001`, etc.), task execution engines, GraphRAG memory nodes, and telemetry dispatchers.

All character identities in this roster are **100% original to PT Koneksi Digital Inovasi (KDI)** and do not inherit any proprietary, character names, or persona combinations from external reference websites.

## 5. Visual Art Direction & Color Harmonies

All characters follow KDI's cozy pastel low-poly art direction:
- Proportions: Chibi 3-head-tall low-poly aesthetic.
- Color Balance: Gentle pastel tones without jarring primaries.
- Lighting: Soft warm diffuse ambient light with soft isometric shadows.
- No copied meshes, textures, or naming conventions from reference websites.
